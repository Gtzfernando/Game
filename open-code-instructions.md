# Instrucciones operativas para OpenCode

1. Leer `docs/SPECIFICATION.md` completo antes de modificar código.
2. No inventar acertijos, respuestas, poemas, pistas, ubicaciones, textos de premio ni QR.
3. El PDF en `docs/Diagrama-de-flujo-original.pdf` es la fuente de verdad visual.
4. Los cambios aprobados en la especificación prevalecen sobre el PDF.
5. No añadir funciones no solicitadas (rankings, cronómetros, chat, pagos, etc.).
6. No exponer `SUPABASE_SERVICE_ROLE_KEY` en el navegador.
7. Implementar validaciones en servidor.
8. Ejecutar lint, typecheck, tests y build antes de declarar trabajo terminado.
9. No declarar el despliegue realizado; dejar el repositorio preparado.
